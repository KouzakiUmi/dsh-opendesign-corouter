# OpenDesign CoRouter 设置界面

## 四个页面

1. **概览**：分别显示 Design Plan 窗口、套餐模型余额、充值余额与总额度。窗口重置时间、订阅账期结束、下次自动刷新和最近更新时间分别标注；未知金额不补零。
2. **模型**：套餐赠送与付费模型分组展示，支持搜索、独立启停、图片输入覆盖、展开参数编辑和恢复默认；上下文窗口用三个互斥档位选择。从当前配置的网关读取目录（OpenAI 兼容 `/models` 接口）；官网公开价格按精确模型 ID 单独读取并显示输入、输出及缓存价格分档。
3. **连接与登录**：桌面优先、独立登录、API Key。已有完整独立会话可整体接替不完整的桌面读数；不把两份账号数据相加。
4. **高级**：在 Chat Completions、Responses、Messages 中选择实际推理协议；查看当前地址，设置凭据引用名、请求超时、流空闲超时、额度刷新间隔、空轮监控与结束回合核验。

## 保存与生效

复选框与配置选择即时显示待保存值，保存反馈位于页签下方；Host 拒绝保存后恢复已接受的值。写操作按顺序提交，各字段独立保持忙态，避免并发配置镜像尚未发布时回跳。首次状态读取与额度刷新并行，保存完成后解除控件忙态，不等待额度网络请求。

只有配置已就绪且允许写入时才开放编辑；加载中、命名空间不可用与只读状态分别给出原因。Schema 转换函数在 Host 表单投影及再次 JSON 序列化后仍保留回调；离线浏览器使用真实 `volatileForm` 投影校验初始配置与每次写入，回归另覆盖多次投影与新浏览器上下文解码。

概览在缺少 Key 或额度登录时提供直接跳转入口；余额为主要指标，时间安排为次级信息，额度解释折叠显示。模型每组默认显示前 6 项，可展开全部；搜索覆盖完整目录。同组已启用模型排在已禁用模型之前，各自保留目录原顺序。默认突出名称、ID 和模型启停；图片输入使用紧凑控件，温度及其他高级参数保持折叠。图片输入标明自动或手动来源，未知能力不展示为已确认；手动覆盖可单独恢复自动。开关采用可点击标签，保留原生键盘及强制颜色支持。

上下文窗口不用自由数字输入，改为“默认 272K / 扩展 500K / 最大 872K”三个互斥档位按钮，并标注这是输入与输出合计的工作总窗口。超过模型已知参考的档位禁用并说明原因，已知参考缺失的模型三档都可选；默认档按参考限幅后显示实际生效的窗口数值。已有自定义数值时按旧值生效，控件显示自定义状态并保留清除入口；旧数值即使与某个档位数值相同也按自定义显示，不被当作该档位。选择档位才会替换它，选择默认档清除覆盖。切换档位与已保存的显式最大输出冲突时拒绝保存、保留原值并提示先清除或调小输出，不静默改写显式值。恢复默认回到默认档，不回到厂商参考的最大容量。

聊天视图在模型选择框旁挂载上下文快捷按钮：仅当当前会话选中的模型属于本插件两个通道之一时显示，取该会话自己的模型目录，按钮文字是当前生效的总窗口。弹层列出同样三档并即时保存，待保存与回滚表现和设置页一致；切换模型时弹层关闭，上一个模型尚未完成的异步结果不写入新模型。弹层可键盘操作，Escape 与点击外部关闭，焦点回到触发按钮，沿用主题令牌并适配窄屏。

两个档位入口共用同一个写入协调器：配置写入逐个提交，同一字段保存期间在两个入口都禁用，等待期间显示待保存值，宿主拒绝后回到宿主值；模型设置按字段差异合并到宿主当前映射上，其他模型与同模型其他字段的并发修改不会被覆盖。

每个额度窗口采用紧凑卡片：标题、剩余百分比、余量条、已用 / 总计积分和恢复时间分层显示，积分摘要不充当进度条刻度；精确数值可通过辅助标签查看。接口报告的剩余积分、窗口开始和重置方式收进默认折叠的“窗口详情”，未知剩余积分保持 `—`，不从百分比反推。状态横幅以最紧张的窗口为依据；读取不完整、过期或到达恢复时间但尚未更新时，不显示“充足”。来源与最近更新时间分别列行，窄屏及详情展开后不产生水平溢出。

刷新时间使用真实计划时间的动态倒计时，刷新中、已到时间和暂停分别显示；窗口恢复与账期结束也显示相对时间，精确时间保留在时间元素的提示和无障碍标签中。窗口到期后的旧数据提示等待更新。页面关闭时清理展示计时器，不额外触发网络读取。

模型开关和参数通过 `configForms` 保存，并作用于宿主模型目录、模型元数据及后续请求。界面分组名称使用“套餐赠送模型”和“付费模型”；Provider ID 作为配置标识保持不变。未填参数继承默认值；保存、失败与只读状态均在控件附近反馈。

思考选项取型号档位与当前协议的交集；默认值先显示摘要，进入编辑后选择、保存或取消，未保存的草稿不影响模型请求。历史默认值超出交集时显示“当前不可用”，保留清除入口；未知型号不由默认值反推能力。未显式选择时保留上游默认档位。

`refreshModels()` 是独立的模型发现操作，固定读取当前网关的 OpenAI 兼容 `/models` 接口。按钮使用“刷新模型目录”，来源与成功提示使用“当前网关”，避免将接口协议误作 OpenAI 官方模型来源。切换推理协议不会切换模型发现协议。`status()` 返回缓存与配置；`refreshQuota()` 合并在途读取并遵守缓存间隔；手动操作使用 `refreshQuotaNow()` 绕过缓存。界面按 `nextRefreshAt` 安排后续刷新；连续失败六次后显示暂停提示，手动刷新恢复。额度来源或刷新间隔保存后立即取数。卸载后停止计时与应用异步结果。

首次打开模型页以及点击“更新价格”时，Host 独立读取官网公开价格目录，不使用推理凭据。模型行显示首档输入与输出单价，多档模型可展开查看所有分档及缓存读写价格；官网未列的值显示“未列出”。页面显示价格更新时间，刷新失败时保留上次成功结果并标注过期。官网报价与网关可用模型、套餐覆盖和实际账单是不同信息。

API Key 保存后清空且不回填，不进入普通设置、URL 或网页存储。设备授权先申请用户码，再打开官方授权页：Host 可用 `playwright-core` 启动一个插件自己的临时 Chrome 窗口（不读取或改动用户已有浏览器配置），官方链接同时保留为手动路径。等待期显示授权码、链接、到期时间与打开结果；授权成功、取消、过期或失败后移除授权码与链接，并关闭插件打开的临时窗口。登录、取消及 Key 保存立即采用动作返回状态，较早的状态读取不能覆盖动作结果。复制按钮使用剪贴板，权限受限时显示可选取的授权链接，复制反馈随登录任务切换而重置。连接页根据可选的 `apiKeySource` 字段显示环境/凭据引用、已保存 Key 或设备授权；旧状态未带来源时显示尚未确认。登录后尚未读取额度时显示待读取状态，认证缺失时才提示重新登录。进行中轮询任务状态，终态后停止；敏感写操作继续检查 Host revision。

## 主题与可访问性

沿用 DSH `--dsw-alias-*` 语义令牌，覆盖浅色、深色、强制颜色和窄屏。原生控件的色彩方案随宿主主题切换，下拉选项使用明确的主题前景和背景，以免系统色彩方案与宿主选择不一致时出现低对比度。输入框和次级按钮边界以主题前景与表面色混合增强辨识度；辅助说明、模型 ID 与紧凑输入使用更易阅读的字号，模型重置按钮保留足够的点击高度。模型分组各自按内容高度排列，避免某一组展开时把另一组撑出大块空白。布局除适配浏览器宽度外，也按设置面板自身宽度调整列数，避免宽窗口中的窄侧栏挤压内容。页签具有完整的 tab 语义及方向键、Home/End 操作；表单控件提供 label，展开按钮提供展开状态，错误与异步反馈分别使用 alert/status。
