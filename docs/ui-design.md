# OpenDesign CoRouter 设置界面

## 四个页面

1. **概览**：分别显示 Design Plan 窗口、套餐模型余额、充值余额与总额度。窗口重置时间、订阅账期结束、下次自动刷新和最近更新时间分别标注；未知金额不补零。
2. **模型**：套餐赠送与付费模型分组展示，支持搜索、独立启停、展开参数编辑和恢复默认。从当前配置的网关读取目录（OpenAI 兼容 `/models` 接口），并显示目录来源、更新时间与失败提示。
3. **连接与登录**：桌面优先、独立登录、API Key。已有完整独立会话可整体接替不完整的桌面读数；不把两份账号数据相加。
4. **高级**：在 Chat Completions、Responses、Messages 中选择实际推理协议；查看当前地址，设置凭据引用名、请求超时、流空闲超时、额度刷新间隔与空轮监控。

## 保存与生效

复选框与配置选择即时显示待保存值，保存反馈位于页签下方；Host 拒绝保存后恢复已接受的值。写操作按顺序提交，各字段独立保持忙态，避免并发配置镜像尚未发布时回跳。首次状态读取与额度刷新并行，保存完成后解除控件忙态，不等待额度网络请求。

只有配置已就绪且允许写入时才开放编辑；加载中、命名空间不可用与只读状态分别给出原因。Schema 的转换函数必须自包含，经过 JSON 传输后仍可在浏览器独立还原和校验。离线浏览器使用构建产物导出的真实 schema 校验初始配置与每次写入。

概览在缺少 Key 或额度登录时提供直接跳转入口；余额为主要指标，时间安排为次级信息，额度解释折叠显示。模型每组默认显示前 6 项，可展开全部；搜索覆盖完整目录。默认突出名称、ID 和开关；能力信息与参数进入可展开区域，摘要标明是否自定义。开关采用可点击标签和至少 44px 行高，保留原生键盘及强制颜色支持。模型容量编辑会核对有效输出上限小于上下文预算，继承目录默认值也参与检查。

每个额度窗口独立呈现：标题与剩余百分比作为主信息，进度条满格表示 100% 剩余；已用、上限、剩余以带标签的三列明细呈现，下次恢复独占一行。窗口开始、重置方式收进默认折叠的“窗口详情”，不与用量和恢复时间串成一句长文。来源与最近更新时间也分别列行。窄屏保留标签和值的关联，详情展开后仍不产生水平溢出；未知剩余金额保持 `—`，不从百分比反推。

模型开关和参数通过 `configForms` 保存，并作用于宿主模型目录、模型元数据及后续请求。界面分组名称使用“套餐赠送模型”和“付费模型”；Provider ID 作为配置标识保持不变。未填参数继承默认值；保存、失败与只读状态均在控件附近反馈。

`refreshModels()` 是独立的模型发现操作，固定读取当前网关的 OpenAI 兼容 `/models` 接口。按钮使用“刷新模型目录”，来源与成功提示使用“当前网关”，避免将接口协议误作 OpenAI 官方模型来源。切换推理协议不会切换模型发现协议。`status()` 返回缓存与配置；`refreshQuota()` 合并在途读取并遵守缓存间隔；手动操作使用 `refreshQuotaNow()` 绕过缓存。界面按 `nextRefreshAt` 安排后续刷新；连续失败六次后显示暂停提示，手动刷新恢复。额度来源或刷新间隔保存后立即取数。卸载后停止计时与应用异步结果。

API Key 保存后清空且不回填，不进入普通设置、URL 或网页存储。设备授权先申请用户码，再打开官方授权页：Host 可用 `playwright-core` 启动一个插件自己的临时 Chrome 窗口（不读取或改动用户已有浏览器配置），官方链接同时保留为手动路径。等待期显示授权码、链接、到期时间与打开结果；授权成功、取消、过期或失败后移除授权码与链接，并关闭插件打开的临时窗口。登录、取消及 Key 保存立即采用动作返回状态，较早的状态读取不能覆盖动作结果。复制按钮使用剪贴板，权限受限时显示可选取的授权链接，复制反馈随登录任务切换而重置。连接页根据可选的 `apiKeySource` 字段显示环境/凭据引用、已保存 Key 或设备授权；旧状态未带来源时显示尚未确认。登录后尚未读取额度时显示待读取状态，认证缺失时才提示重新登录。进行中轮询任务状态，终态后停止；敏感写操作继续检查 Host revision。

## 主题与可访问性

沿用 DSH `--dsw-alias-*` 语义令牌，覆盖浅色、深色、强制颜色和窄屏。页签具有完整的 tab 语义及方向键、Home/End 操作；表单控件提供 label，展开按钮提供展开状态，错误与异步反馈分别使用 alert/status。
