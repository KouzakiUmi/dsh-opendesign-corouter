# OpenDesign CoRouter 设置界面

## 四个页面

1. **概览**：分别显示 Design Plan 窗口、套餐模型余额、充值余额与总额度。窗口重置时间、订阅账期结束、下次自动刷新和最近更新时间分别标注；未知金额不补零。
2. **模型**：按当前账号逐模型权益分组，支持搜索、启停、图片输入覆盖和恢复默认。上下文、思考控制及最大输出直接可见；协议、温度、Top P、容量证据和完整价格放进高级参数。目录与官网价格分别读取。
3. **连接与登录**：桌面优先、独立登录、API Key。已有完整独立会话可整体接替不完整的桌面读数；不把两份账号数据相加。
4. **高级**：全局协议、凭据引用、超时、额度刷新间隔和监控选项。

## 模型参数与聊天入口

模型卡片以名称和精确 ID 为主，启用与权益紧随其后。常用参数从卡片直接操作，不必先展开价格和协议。图片输入标明自动或手动来源；未知图片能力显示尝试发送，手动覆盖可单独恢复自动。每组默认显示六项，搜索覆盖完整目录；同组启用项优先，各自保持目录顺序。

上下文采用参考 kxy 的一行容量分段，而容量策略由本插件的共享策略产生。例如十进制 1M 显示 `256K / 512K / 1M`，二进制 262,144 显示 `64K / 128K / 256K`，1,050,000 最大显示 `1.05M`。标题与辅助名称保留档位含义，提示中给出精确 token 数及输入与输出合计口径；设置页可展开简短说明。已知参考缺失时直接显示“容量未知”，不绘制带推测数字的三段，有旧覆盖时提供恢复默认。旧数字值始终显示自定义，即使等于某档也不自动转换。

分段使用原生按钮和 `aria-pressed`，选中项同时有边框、底色与字重。方向键、Home、End 仅移动焦点，Enter 和空格才提交，Tab 可正常离开。三个容量按钮保持同行，面板变窄时标签和说明可换行；不依赖弹层定位和外部关闭事件。保存过程中组内锁定并显示忙态，完成后在原控件仍拥有焦点时恢复焦点，避免打断用户转往其他控件。

聊天模型选择框旁直接使用同一分段控件，仅对当前会话选择的 CoRouter 模型显示，取该会话自己的模型目录。改动写入此型号的共享默认，其他使用此型号的会话同步；已准备请求保留快照。切换模型重挂控件，迟到的旧模型状态、提示或保存结果不会写入新模型。两个入口共用写入协调器，按字段差异合并到宿主当前映射，保留其他模型及同型号其他字段的并发修改。

思考行区分四种能力：有离散强度、仅开关、固定开启、尚未核实。MiMo 与 Qwen3.7 等开关型显示“开启 / 关闭”，不将内部 wire 值 `high` 当成真实强度。Kimi K2.7 显示固定思考；未知型号直接说明未核实。协议暂不提供控制时说明协议限制，不据此断言模型不思考。原始能力与当前协议有效能力分别保留，切回支持协议时选项恢复。默认思考采用编辑、保存、取消；草稿不影响请求，失败保留草稿并同时展示外部变化，旧不兼容设置仍可清除。

## 保存、刷新与状态

开关、协议和上下文选择立即显示待保存值，数值离开输入框后提交，留空继承。Host 拒绝后恢复已接受值。写操作串行提交并记录所有待保存字段；配置就绪、可写性与额度请求分开，额度网络延迟不会使已保存控件保持禁用。加载、不可用和只读原因在控件附近说明。

上下文三档按精确型号的当前参考生成，最大档等于完整参考，较小网关参考重算三档；未知不补值。输出在总窗口内预留，显式最大输出冲突会拒绝切档并保持原值。恢复默认清除 numeric 与 tier，不会改用厂商参考的最大容量。Schema 回调在 Host 投影和再次 JSON 序列化后仍可重建；离线浏览器使用真实 `volatileForm` 校验写入。

模型目录读取固定 OpenAI 兼容 `/models`，推理协议切换不改变发现协议。按当前 Key 对应工作区和成员绑定缓存及逐模型权益；刷新失败保留可安全继续使用的目录并说明阶段，不能跨身份恢复覆盖。公开价格不使用推理凭据，按精确 ID 保存价格分档，首次打开及手动刷新读取；失败保留旧快照并标明过期，不将缺价推断为免费。

额度每个窗口分别显示剩余百分比、余量条、已用/总计积分和恢复时间。技术详情、接口剩余值、来源和更新时间分开；缺失、过期或不完整读数不显示“充足”。动态倒计时来自真实计划时刻，恢复、账期和下次刷新分别标明。页面关闭清理计时器；自动失败六次暂停，手动刷新恢复。

设备授权通过 Host 自建临时窗口或官方手动链接完成，不操作已有浏览器配置；等待期只展示公开授权码/链接/到期，终态清理。API Key 保存后清空且不回填。登录、取消和 Key 动作结果优先于较早状态读取。复制失败提供可选取链接，反馈随任务重置。

## 主题与验证

沿用 DSH `--dsw-alias-*` 语义令牌，原生下拉颜色与 color-scheme 跟随宿主而非系统；分段、输入和按钮保留清晰焦点环及 forced-colors 选中边界。布局同时适配 viewport 与设置面板宽度，两组按各自内容高度排布。错误用 alert，正常异步反馈用 status。

[组件测试](../test/client-model-controls.test.ts)、[设置测试](../test/client-ui.test.ts)与[离线浏览器](../scripts/ui-smoke.mjs)覆盖参数前置、四种思考能力、协议切回恢复、共享默认、pending/回滚、切模型保存竞态、按钮键盘、窄面板、主题及销毁。预览为模拟数据，不代替真实网关推理和已安装 GUI 的验收；`ODC_PREVIEW_DIR` 可隔离截图。
