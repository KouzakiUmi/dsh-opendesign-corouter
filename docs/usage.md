# 连接与使用

## 推理连接

CoRouter 工作空间 API Key 是模型调用凭据，桌面令牌与控制台 Cookie 不能替代它。默认 OpenAI 兼容基址为 `https://amr-link.open-design.ai/v1`，本插件使用 Chat Completions。

可选择：

- 在启动 DSH 的环境中提供 `COROUTER_API_KEY`，或沿用同名 DSH 凭据引用。
- 在设置的“连接与登录”页保存插件专属 Key。

现有引用 / 环境凭据优先于插件内保存值，因此保存新 Key 不会覆盖共享引用。输入保存后清空，不回填。高级页可以修改引用名和基址；非回环地址要求 HTTPS，不允许 URL 内嵌凭据、查询参数或片段。

## 额度身份

读取顺序为桌面已有登录态 → 插件保存的独立会话 → `OPEN_DESIGN_COOKIE` / `OPEN_DESIGN_SESSION` 引用或启动环境变量。关闭“优先使用桌面登录态”后，不读取桌面文件。

### 已有桌面端

默认只读生产 profile，配置目录沿用 `AMR_HOME`，未指定时是主目录下 `.amr`。控制面只信任 `https://amr-api.open-design.ai`，不会将非生产令牌改投生产。

桌面通道用钱包接口与 Vela 固定只读命令。Windows 默认检测官方安装位置；其他安装布局可通过绝对路径 `OPENDESIGN_VELA_PATH` 指定可信 Vela。插件不校验其签名，也不下载 CLI。

桌面认证失效时，会尝试独立会话；不拼接不同身份的额度。桌面接口权限较窄，某些分池可能未知，这是部分读取，不表示余额为零。

### 没有桌面端

1. 确保本机安装 Google Chrome。
2. 点击“登录并保存会话”，在隔离窗口中的官方页面自行登录，必要时亲自完成验证。
3. 等待额度接口验证；成功后会话自动保存至 DSH 凭据服务。

按钮本身明确授权本次保存，无第二次确认。取消、关闭窗口、五分钟超时或停用插件会清理自身浏览器；持久化一旦成功，之后取消不能撤回。会话 Cookie 会按浏览器提供的最早过期时间保存，没有声明时不猜有效期。

需要完整控制台分池时，可先独立登录，再关闭桌面优先。额度身份未与推理 Key 的账号或工作区作一致性核验，请自行确认。

## 四层额度

| 显示 | 口径 |
| --- | --- |
| 套餐赠送窗口 | 服务端报告的各窗口用量 / 上限 / 剩余 / 重置时间 |
| 套餐余额 | `subscriptionCredits / creditsPerUsd` |
| 充值 / 赠送金额 | `rechargeCredits / creditsPerUsd` |
| 总额度 | 接口报告的钱包总余额或等价总额字段 |

窗口不是钱包分母，不外推月总额，不把总额再次加到分池上。缺失字段显示 `—`。团队工作区不会混入个人钱包。权限不足允许已成功层独立显示；认证失败不会被另一层成功掩盖。刷新有短缓存，连续点击不代表每次都重新请求。

## 模型与空轮监控

两个 Provider 的目录互斥，但计费仍由服务端决定。套餐组继承同端点的 opendesign-go 元数据；其余模型缺失能力字段保持未知，不按名称猜思考档位或图像能力。完整 ID 见 [模型表](../src/catalog.ts)。

“高级”中的空轮开关只控制赠送模型、有工具的对话步骤：stop、从未出现工具调用、可见文本为空 / 仅残渣时，改写成可重试错误。已有真实回答、工具步或非 stop 结束不改写。真正没有任何内容的异常响应始终会被适配器拒绝。

重试由宿主插件 / 策略执行，监控本身不重试。它不保证上游恢复，也不能阻止上游的余额回退计费。
