# 连接与使用

## 推理连接

模型调用使用 CoRouter API Key 或设备授权取得的 runtimeKey；控制面的 controlKey 和旧控制台 Cookie 不能替代推理令牌。默认网关为 `https://amr-link.open-design.ai/v1`；在“高级”页直接选择 Chat Completions、Responses 或 Messages 协议，无需手填三套地址。具体模型的协议兼容性仍由服务端决定，见[协议说明](protocols.md)。

可选择：

- 在启动 DSH 的环境中提供 `COROUTER_API_KEY`，或沿用同名 DSH 凭据引用。
- 在设置的“连接与登录”页完成设备授权，自动保存控制面和推理令牌。
- 单独保存插件专属 API Key，覆盖设备授权的推理令牌。

推理凭据按现有引用 / 环境 → 手动保存的 API Key → 设备授权 runtimeKey 的顺序选择。设备推理令牌只用于官方 `https://amr-link.open-design.ai` origin，自定义网关需单独配置 Key，因此保存新 Key 不会覆盖共享引用。输入保存后清空，不回填。高级页提供协议、引用名、请求超时、流空闲超时和额度自动刷新间隔。旧配置里的自定义基址继续生效；非回环地址要求 HTTPS，不允许 URL 内嵌凭据、查询参数或片段。

## 额度身份

读取顺序为桌面已有登录态 → 插件保存的设备授权（或旧版 Cookie 会话） → `OPEN_DESIGN_COOKIE` / `OPEN_DESIGN_SESSION` 引用或启动环境变量。关闭“优先使用桌面登录态”后，不读取桌面文件。

### 已有桌面端

默认只读生产 profile，配置目录沿用 `AMR_HOME`，未指定时是主目录下 `.amr`。控制面只信任 `https://amr-api.open-design.ai`，不会将非生产令牌改投生产。

桌面通道用钱包接口与 Vela 固定只读命令。Windows 默认检测官方安装位置；其他安装布局可通过绝对路径 `OPENDESIGN_VELA_PATH` 指定可信 Vela。插件不校验其签名，也不下载 CLI。

桌面认证失效时，会尝试独立会话；不拼接不同身份的额度。桌面接口权限较窄，某些分池可能未知，这是部分读取，不表示余额为零。

### 没有桌面端

1. 点击“开始设备授权”，取得授权码后插件自动尝试打开一次临时 Chrome 授权窗口。
2. 若窗口未打开，页面会显示失败提示，可点击“在新窗口打开授权页”重试；也可点“复制链接手动打开”，把官方链接放到你常用浏览器的已有登录态、密码管理器和自动填充里使用。
3. 核对授权码并在官方页面确认；返回设置页，等待显示授权已保存。设备授权同时取得 controlKey 与 runtimeKey，由 DSH 凭据服务原子保存到本插件的独立记录。

临时窗口是独立的新 Chrome 会话：不读取、不修改你正在使用的浏览器配置，也不在该页面代填、代点或读取内容。一次打开动作（含失败后的清理）约 20 秒内结束或报失败，不会无限转圈。正常情况下同时只有一个临时窗口；上一个窗口若因浏览器自身原因迟迟不退出，下一个打开可能在它仍有残留进程时开始，插件不会为了等待它而卡住你的操作。没有安装 Chrome 时按钮会提示无法启动，此时请用“复制链接手动打开”。DSH 桌面外壳会拦截页面内的新窗口跳转，这也是需要由插件自己打开窗口的原因。

官方页面确认后自动保存。取消、超时或停用插件会停止轮询，并请求关闭插件打开的临时窗口（每个清理阶段最多等待约 5 秒，超时后不再阻塞）；插件不关闭你自己打开的浏览器，关闭授权窗口也不自动取消任务。等待上限取服务端授权码到期时间与本地五分钟上限中较早者。持久化一旦成功，之后取消不能撤回。授权码到期时间不是令牌过期时间；旧版已保存 Cookie 仍兼容读取，未自动迁移或删除。

需要更多额度信息时，可先完成设备授权；接口权限不足时相应分池仍显示未知，不保证设备令牌与控制台 Cookie 权限相同。桌面结果不完整且独立会话能读到完整额度时，会整体使用独立会话并标明来源，不必再手工关闭桌面优先。额度身份未与推理 Key 的账号或工作区作一致性核验，请自行确认。

## 四层额度

| 显示 | 口径 |
| --- | --- |
| 套餐赠送窗口 | 服务端报告的各窗口用量 / 上限 / 剩余 / 重置时间 |
| 套餐余额 | `subscriptionCredits / creditsPerUsd` |
| 充值 / 赠送金额 | `rechargeCredits / creditsPerUsd` |
| 总额度 | 接口报告的钱包总余额或等价总额字段 |

窗口不是钱包分母，不外推月总额，不把总额再次加到分池上。缺失字段显示 `—`。窗口的重置时间、订阅池账期结束与下次自动拉取时间分别显示；其中账期来自 `subscriptionCurrentPeriodEnd`，不从用量反推。团队工作区不会混入个人钱包。自动刷新遵守缓存间隔；手动“刷新额度”立即重新取数，同时合并已有在途请求。读取失败按 5、10、20、40、60 秒退避，连续六次失败后暂停自动重试；手动刷新或修改额度来源可恢复。仍保留的旧读数会明确标记。

## 模型与空轮监控

模型页可从 **OpenAI `GET /models`** 拉取目录，和当前选择的推理协议完全分离。两个 Provider 的目录互斥，计费仍由服务端决定；已知套餐模型保留分组，新发现的对话模型进入付费组，未知能力不按名称推断。内置 ID 见 [模型表](../src/catalog.ts)。

每行提供独立开关、参数编辑和恢复默认。温度、top-p、默认最大输出、上下文预算与默认思考深度保存到该模型的设置中；空白表示继承。单次请求的温度和思考档位优先于模型默认值；输出长度仍受该模型配置的最大输出与剩余上下文约束。关闭模型后，它从宿主模型列表隐藏，直接调用也会被拒绝；已经准备好的请求保留原配置快照。

容量设置是本地预算，不会扩大服务端限制。最大输出必须小于有效上下文预算；编辑时会同时检查显式值和继承值。部分协议或模型不支持全部采样与思考参数，不兼容的明确设置会被拒绝，不会静默丢弃。

设置会自动保存：开关与协议选择立即提交，数值离开输入框时提交。页签下方显示保存结果；失败的开关恢复原值。加载中、配置不可用或只读时会说明原因。参数编辑区默认折叠，展开后查看能力信息与修改默认参数。

“高级”中的空轮开关只控制赠送模型、有工具的对话步骤：stop、从未出现工具调用、可见文本为空 / 仅残渣时，改写成可重试错误。已有真实回答、工具步或非 stop 结束不改写。真正没有任何内容的异常响应始终会被适配器拒绝。

重试由宿主插件 / 策略执行，监控本身不重试。它不保证上游恢复，也不能阻止上游的余额回退计费。
