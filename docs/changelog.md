# 更新记录

## 0.1.5

- 修复 DSH 桌面窗口内“打开授权页”点击无反应：外壳会拒绝页面发起的 `target="_blank"` 跳转。
- 授权页改由 Host 用 `playwright-core` 启动一个临时 Chrome 窗口显示；单实例、端到端预算有界、失败即清理、终态与卸载时关闭。
- 保留官方链接作为手动路径，按钮回退为“复制链接手动打开”；临时窗口不读取或改动用户浏览器配置。
- 新增 `openActivationPage` RPC（只返回固定代码，不含 URL 或浏览器句柄），并补离线回归与 UI 冒烟覆盖。
- `playwright-core` 改为运行时依赖（Apache-2.0，已补第三方声明），仍不下载浏览器，使用本机 Chrome。

## 0.1.4

- 独立登录改为设备授权：普通浏览器打开官方授权页，沿用现有配置、密码管理器与自动填充。
- 双令牌原子保存到 DSH 凭据服务；显式 Key 优先，设备推理令牌仅用于请求快照中的官方网关。
- 设备额度独立读取，保留权限不足、未知分池及团队/个人工作区边界；兼容读取旧 Cookie 会话。
- 增加设备授权、取消与保存竞态、安全链接及离线 UI 回归；Playwright 仅用于开发测试，不再作为运行依赖。
- 真实账号授权、上游令牌权限和真实推理仍待实测；未加入多账户与自动轮换。

## 0.1.2

- 设置页增加逐模型启停、参数编辑及恢复默认，改动作用于真实模型目录、元数据和请求。
- 支持 Chat Completions、Responses、Messages 三种推理协议；模型发现固定走 OpenAI `/models`，不随推理协议变化。
- 额度补充订阅账期、窗口重置及自动刷新时间；桌面读数不完整时可整体使用完整独立会话。
- 手动刷新绕过缓存；自动读取失败逐步退避，六次后暂停，支持手动恢复。瞬时失败保留并标记同一身份的旧读数。
- 图片读取失败改为明确的占位说明，保留用户取消语义；修正钱包、套餐、权限、凭据与限流错误分类。
- 保留宿主统一模型重试和独立赠送模型空轮监控，避免适配器重复发送请求。
- 更新配置与协议文档，并增加真实 Loader 配置更新、流式终止、交互持久化和主题回归验证。

## 0.1.1

- 采用 MIT 许可，提供 npm 安装来源与标签触发的 GitHub OIDC trusted publishing。
- Zod 升级至 4.6.6，修复 GHSA-mrhx-c7xc-m3w5 涉及的集合校验内存耗尽问题。

- 主按钮采用宿主按钮前景色令牌，输入框占位文字显式跟随主题。
- 暗色错误提示的测量对比度由 4.24:1 提升至 4.95:1。
- 加入官方主题离线夹具，覆盖亮→暗→亮、四页签、悬停、焦点、错误、移动布局和强制颜色；这些不是运行中 GUI 或实号验收。

## 0.1.0

- 两个独立模型 Provider：12 个套餐赠送模型与 21 个其他公开对话模型。
- 四层额度、桌面登录态优先、无桌面端独立登录。
- 套餐赠送模型独立空轮监控开关。
- 四页签设置 UI，官方 Core 0.2.1-rc.3 类型 / 构建及 Loader 生命周期隔离验证。

npm 上的实际版本与 dist-tag 以 registry 为准；测试构建见仓库 Actions。
