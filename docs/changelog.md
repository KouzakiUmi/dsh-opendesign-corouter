# 更新记录

## 0.1.10

- 设置页调整信息层级、状态提示与窄面板布局；自动刷新、额度恢复和账期结束显示相对时间。
- 窗口卡片以紧凑的已用 / 总计摘要和余量条展示，状态按最新窗口数据区分；接口剩余积分可在窗口详情中查看。
- 模型页按精确型号显示官网参考价格和分档，支持更新价格；读取失败时标注并保留上次成功结果。

## 0.1.9

- 设置页面改善辅助文字和模型操作的可读性；模型分组不再互相撑高，并根据设置面板实际宽度调整布局。
- 设置界面的原生下拉选项跟随宿主深浅主题，并增强输入框与次级按钮边界的可见性；补充选项及控件边界的离线对比度检查。
- 内置目录新增 GPT-6.1 Terra；其厂商能力与当前工作区计费分类证据分别记录，网关实际推理能力尚待验证。

## 0.1.8

- 修复配置在 Host 表单投影后丢失转换回调、导致设置一直显示载入中的问题；增加真实 Host 投影和多次 JSON 解码回归。
- 按逐型号官方资料更新思考档位，并统一选择器、设置页和请求协议的可用集合；历史无效默认值可清除，未知值不生成能力声明。
- DeepSeek V4.1 Flash 空轮检测补充 `rea:tool_calls` 残留识别，附加监控仅作用于该型号的工具对话。

## 0.1.7

- 额度概览改为逐窗口分层：剩余百分比与余量条、用量三列、独立恢复时间；窗口开始与重置方式折叠展示。
- 数据来源和更新时间分行排列，补充窄屏布局及详情展开回归，不改变额度查询与金额口径。
- 模型刷新按钮改为“刷新模型目录”，来源和提示明确为当前网关，避免把 OpenAI 兼容接口误解为 OpenAI 官方模型来源。

- 登录、取消及 API Key 保存直接采用动作返回状态，避免额外状态读取失败时出现错误提示或丢失自动开窗。
- 授权链接支持实际复制；剪贴板不可用时提供可选取的链接。
- 显示当前生效的推理凭据来源，保存的 Key 被环境或凭据引用优先覆盖时给出说明。
- 额度待首次读取与需要重新登录分别反馈；模型选择器更新失败时保留原目录并支持重试。
- 统一设置字段与公开状态的数值下限，优化模型分组名称并更新登录说明与验证记录。

## 0.1.6

- 修复真实设备授权链接的 `deviceId` / `userCode` 参数校验；等待确认时的空令牌不再误判失败，避免授权窗口闪退。
- 开始设备授权后自动尝试打开一次临时 Chrome；保留失败提示、手动重试与官方链接。
- 增加 Gemini 4 Argon、Kimi K3.1 Pro、MiniMax M3.1 Flash、Muse Spark 1.3、Muse Wonder，内置目录共 38 项。
- 根据同工作区的服务端预检，将 MiniMax M3.1 Flash 纳入附赠通道，其余新增项归付费通道；实际覆盖与扣款仍由服务端决定，未知能力保持未知。
- 补充真实设备授权及模型目录/计费预检证据，维护入口记录后续目录更新的查询步骤。

## 0.1.5

- 修复 DSH 桌面窗口内“打开授权页”点击无反应：外壳会拒绝页面发起的 `target="_blank"` 跳转。
- 授权页改由 Host 用 `playwright-core` 启动一个临时 Chrome 窗口显示；单实例、端到端预算有界、失败即清理、终态与卸载时关闭。
- 保留官方链接作为手动路径，按钮回退为“复制链接手动打开”；临时窗口不读取或改动用户浏览器配置。
- 新增 `openActivationPage` RPC（只返回固定代码，不含 URL 或浏览器句柄），并补离线回归与 UI 冒烟覆盖。
- `playwright-core` 改为运行时依赖（Apache-2.0，已补第三方声明），仍不下载浏览器，使用本机 Chrome。

## 0.1.4

- 独立登录改为设备授权：普通浏览器打开官方授权页，沿用现有配置、密码管理器与自动填充。
- 双令牌原子保存到 DSH 凭据服务；显式 Key 优先，设备推理令牌仅用于请求快照中的官方网关。
- 设备额度独立读取，保留权限不足、未知分池及团队/个人工作区边界；兼容读取旧 Cookie 会话。
- 增加设备授权、取消与保存竞态、安全链接及离线 UI 回归；Playwright 仅用于开发测试，不再作为运行依赖。
- 真实账号授权、上游令牌权限和真实推理仍待实测；未加入多账户与自动轮换。

## 0.1.2

- 设置页增加逐模型启停、参数编辑及恢复默认，改动作用于真实模型目录、元数据和请求。
- 支持 Chat Completions、Responses、Messages 三种推理协议；模型发现固定走 OpenAI `/models`，不随推理协议变化。
- 额度补充订阅账期、窗口重置及自动刷新时间；桌面读数不完整时可整体使用完整独立会话。
- 手动刷新绕过缓存；自动读取失败逐步退避，六次后暂停，支持手动恢复。瞬时失败保留并标记同一身份的旧读数。
- 图片读取失败改为明确的占位说明，保留用户取消语义；修正钱包、套餐、权限、凭据与限流错误分类。
- 保留宿主统一模型重试和独立赠送模型空轮监控，避免适配器重复发送请求。
- 更新配置与协议文档，并增加真实 Loader 配置更新、流式终止、交互持久化和主题回归验证。
