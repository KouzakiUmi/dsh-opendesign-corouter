# 更新记录

## 0.1.18

- 思考增量补读结构化的 `reasoning_details[].text`：网关把同一段思考写在 `reasoning` 与 `reasoning_details` 里时只取第一个有内容的拼写；此前漏读会让思考块打不开，推理模型的输出整段丢弃，最终表现为空响应。
- 目录快照保存只在版本冲突（`SETTINGS_CONFLICT`）时重试一次，其他写入失败立即报未保存：每次写入都会重写整份配置并可能重建插件树，重复一次注定失败的写入并不划算。
- 配置不再默认写入凭据引用名：DSH 模型页会读取配置里的引用名并当真，本机没有该引用时给两条通道打上“API 密钥缺失”，还把这两条通道当成待配置通道强制展开配置卡片。现在只有用户显式填写引用名才会写进配置，请求内部仍沿用 `COROUTER_API_KEY`：模型页不再报告这两条通道缺密钥。设置页的引用名输入框改为留空表示不命名（默认引用名只作占位提示），保存空值即清除已保存的引用名，避免顺手一存就把默认值固化成显式引用。模型页的就绪判定是全局合并的：只要这层不报缺失，页面就不再为任何通道弹出配置引导。

## 0.1.17

- 在线读取的模型目录会保存为配置快照，宿主重启后在同一网关下继续使用，不再退回内置目录；切换网关后旧快照不生效。
- 快照按不可信输入校验并与状态传输的字段上限一致：未知字段、越界数值、重复 ID、非法模态/网关/时间一律忽略，损坏数据不阻断设置页加载。
- 保存失败或配置服务不可写时只提示未保存，本次运行仍使用新目录；并发刷新按顺序落盘，只保留最新目录，目录快照本身不触发连接或凭据失效提示。

## 0.1.16

- 上下文窗口改为「默认 272K / 扩展 500K / 最大 872K」三个互斥档位，档位是输入与输出合计的工作总窗口；目录参考只决定档位是否可选，旧数值覆盖按自定义值保留且不受参考限幅。
- 聊天输入区新增会话级上下文快捷控件，按当前会话模型显示生效总窗口，并与设置页共用同一写入协调器、待保存值与回滚；切换模型时弹层关闭。
- 结束回合核验改为独立开关并默认关闭；关闭时不注册收尾工具、不追加核验步骤。监控范围明确为本插件 Plan Provider 的 DeepSeek V4.1 Flash 工具对话。
- 修复上下文快捷弹层首次打开瞬间停留在左上角、吞掉外部点击而无法关闭的问题。
