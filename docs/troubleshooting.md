# 常见问题

## 已独立登录，为什么还提示没有推理 Key？

独立登录用于查额度，不会创建 API Key。请在 CoRouter 工作空间创建模型调用 Key，再通过环境引用或插件设置配置。不要把 Cookie / controlKey 填进 Key 输入框。

## 保存了新 Key，为什么仍像在使用旧 Key？

同名 DSH 凭据引用 / 启动环境优先。插件保存只修改自己的专属记录，不覆盖共享来源。请核对高级页引用名与 DSH 启动环境，只确认存在性 / 非空性，不输出秘密。

## 桌面能登录，但只有总额或少了分池？

桌面凭据权限可能有限；Vela 不可用也会使窗口未知。先看页面指引，不把未知视为没额度。可独立登录控制台，再关闭桌面优先，整体切换到该身份读取，不能把两份数据相加。

## 登录窗口打不开或验证超时？

独立登录依赖本机 Chrome，不自动下载。检查 Chrome 可启动性；在弹窗内亲自完成官方登录 / 人机验证。超时或关闭窗口不会保存，重新发起时会建立新尝试。

## 为什么看到认证失效或版本冲突？

认证失效需由对应身份重新登录。版本冲突表示配置 / 凭据已在本次操作开始后变化：刷新状态后再操作，不反复提交旧页面。

## 空轮开关开着，为什么没有自动继续？

开关只把指定空轮改写为 `EMPTY_RESPONSE`。宿主必须另有重试策略；未启用时只显示错误。达到重试上限也不会继续；重复请求可能消耗额度。

## 为什么“套餐赠送”模型用了钱包余额？

Provider 是目录分组，不是强制服务端扣款池的开关。是否回退到钱包取决于上游权益 / 计费规则，请以官方控制台和账单为准。

## 新仓库为什么不能直接用 Git URL 安装？

源码不提交构建后的 `lib`，也没有安装时自动构建脚本。请用成功 CI 的 `.tgz` artifact，或克隆源码后按 [开发说明](development.md) 构建。Actions ZIP 需要先解压，不能当成插件 tarball。

## CI artifact 过期了？

artifact 不是永久 Release。可在有权限时手动运行 CI，或从源码重建；尚未发布的 Release / npm 包没有可用下载地址。

## 反馈问题应附什么？

插件版本、DSH Core 版本、系统、操作步骤与脱敏错误说明即可。不要上传真实 Key、Cookie、凭据文件、完整请求头或含秘密的 URL。界面离线预览不是账号在线验收证据。
