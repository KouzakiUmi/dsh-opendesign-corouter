# 常见问题

## 已独立登录，为什么还提示没有推理 Key？

新设备授权会同时取得控制面和推理令牌；在官方网关且没有更高优先级 Key 时，可直接用于推理。旧版 Cookie 登录只用于查额度，自定义网关也不会自动收到设备推理令牌。请核对网关和凭据来源，必要时单独配置 API Key。不要把 Cookie / controlKey 填进 Key 输入框。

## 保存了新 Key，为什么仍像在使用旧 Key？

同名 DSH 凭据引用 / 启动环境优先。插件保存只修改自己的专属记录，不覆盖共享来源。请检查高级页引用名对应的环境变量或宿主凭据是否已配置；反馈问题时隐藏凭据值。

## 桌面能登录，但只有总额或少了分池？

桌面凭据权限可能有限；Vela 不可用也会使窗口未知。可在“连接与登录”中尝试设备授权；该令牌的接口权限仍由服务端决定，不能保证所有分池可读。桌面结果不完整时，插件会尝试整体使用已有的完整独立会话，并标明实际来源；两份账号数据不会相加。需要明确选择独立账号时，仍可关闭桌面优先。

## 授权页打不开或设备码过期？

点击“开始设备授权”后，插件会自动打开临时 Chrome 授权窗口；未打开时可点“在新窗口打开授权页”重试。也可点“复制授权链接”，在常用浏览器中粘贴打开；复制不可用时选取页面给出的链接。临时窗口是独立会话，不含你原有的登录态，需要在该窗口登录一次再确认设备码。页面只接受官方授权地址；未出现链接时查看申请失败提示。服务端或本地等待时限到期后需重新申请，不重复使用旧码。关闭窗口不会停止后台等待，需要时点击“取消登录”。确认授权后如提示保存冲突或失败，刷新设置并重新开始。

## 为什么看到认证失效或版本冲突？

认证失效需由对应身份重新登录。版本冲突表示配置 / 凭据已在本次操作开始后变化：刷新状态后再操作，不反复提交旧页面。

## 异常结束监控开着，为什么没有自动继续？

监控仅适用于 DeepSeek V4.1 Flash 的工具对话。空回答、协议残留或符合规则的操作说明会变为 `OPENDESIGN_EOT`，在 Agent 步骤内按退避间隔持续重试；取消运行或关闭监控可停止恢复。没有终态的流在工具调用开始前中断时归为 `TRANSPORT`，仍依赖宿主原有重试策略。文字识别无法判断所有自然语言，可能漏检或误判；重复请求可能消耗额度。

## 为什么“套餐赠送”模型用了钱包余额？

Provider 是目录分组，不是强制服务端扣款池的开关。是否回退到钱包取决于上游权益 / 计费规则，请以官方控制台和账单为准。

## 请求或压缩时出现 HTTP 413？

413 表示请求内容过大，不一定是模型的 token 上下文窗口过小。长会话里历史图片会再次内联发送，编码后的体积可能远大于原文件；工具、文本和思考回放也占请求体空间。

插件按“高级”中的图片预算请求宿主卸载旧图片；如果仍收到 413 且请求含可发送的图片，会进一步请求卸载并重试。宿主以占位符替换后续请求中的旧图片，不删除原附件；需要再次查看时可重新附加图片。该恢复依赖宿主启用 `compaction-image-offload`，并且压缩摘要请求也经过本插件；若没有该能力、没有图片可卸载，或剩余文本和工具本身过大，仍需减少输入或换用可处理该请求的摘要模型。下调图片预算可提前保留请求空间，但它不是网关保证的大小上限。

## 新仓库为什么不能直接用 Git URL 安装？

源码不提交构建后的 `lib`，也没有安装时自动构建脚本。常规安装使用 npm 包 `dsh-opendesign-corouter`；也可用成功 CI 的 `.tgz` artifact，或按 [开发说明](development.md) 构建本地目录。Actions ZIP 需要先解压。

## CI artifact 过期了？

CI artifact 保留 14 天。常规安装使用 npm 包；测试构建过期后，可在有权限时手动运行 CI，或从源码重建。

## 反馈问题应附什么？

插件版本、DSH Core 版本、系统、操作步骤与脱敏错误说明即可。不要上传真实 Key、Cookie、凭据文件、完整请求头或含秘密的 URL。界面离线预览不是账号在线验收证据。
